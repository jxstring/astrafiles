# AstraFiles

**A modern, fast and cross-platform file manager built with Kotlin.**

AstraFiles is a desktop file manager focused on a clean interface, convenient file navigation and a modern user experience.

## 🚀 Run

AstraFiles requires **Java 17**.

If the Gradle Wrapper has not been generated yet, run:

```bash
~/gradle-9.0.0/bin/gradle wrapper --gradle-version 9.0.0
```

This command **generates the Gradle Wrapper** for the project.

After generating the wrapper, run AstraFiles with:

```bash
./gradlew run
```

If required, make the wrapper executable:

```bash
chmod +x ./gradlew
```

Then:

```bash
./gradlew run
```

---

## 🔨 Build

Build AstraFiles:

```bash
./gradlew build
```

Clean build files:

```bash
./gradlew clean
```

---

## 🧩 Requirements

* **Java 17**
* **Git**
* Internet connection for downloading Gradle dependencies

Gradle does not need to be installed globally once the Gradle Wrapper has been generated.
