**A modern, fast and cross-platform file manager built with Kotlin.**

## 🚀 Run

AstraFiles requires **Java 17**.

If the Gradle Wrapper is not present, generate it with:

```bash
~/gradle-9.0.0/bin/gradle wrapper --gradle-version 9.0.0
```

This command only **generates the Gradle Wrapper** for the project.

Once the wrapper is available, start AstraFiles with:

```bash
./gradlew run
```

If necessary, make the wrapper executable:

```bash
chmod +x ./gradlew
```

---

## 🛠️ Build

Build the project:

```bash
./gradlew build
```

Clean build files:

```bash
./gradlew clean
```
